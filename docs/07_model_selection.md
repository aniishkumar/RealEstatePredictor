# Model selection
`ml/train.py` uses an 80/20 reproducible train/test split. It fits Linear Regression, Random Forest, and Histogram Gradient Boosting with the same preprocessing, records held-out MAE/RMSE/R², and selects lowest MAE then RMSE. Actual numbers are deliberately only in `models/model_metrics.json`, generated by the run.

Why not choose R² alone? It is relative to a mean baseline and may conceal costly large errors; MAE is easier to explain in dollars. A stronger model is selected only if its held-out error supports the complexity tradeoff.
